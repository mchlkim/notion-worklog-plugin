`notion-worklog-skill` 스킬의 **3) 종료** 절차를 수행한다.

결과 값: $ARGUMENTS

1. 이번 세션에서 만든 카드를 쓴다. 모르면 `상태` 가 `계획`/`진행중` 인 카드를 조회해 사용자에게 확인받는다.
2. `결과` · `완료일` · `브랜치/커밋` · `푸시` 를 채운다. 결과 인자가 없으면 실제 작업 결과에서 추론한다.
   `브랜치/커밋` 은 `[브랜치@짧은해시](<원격URL>/commit/<전체해시>)` 로 넣어 커밋으로 링크한다.
   원격이 없으면 링크 없이 `브랜치@짧은해시`, git 레포가 아니면 비워 둔다.
   `(pushed)` 같은 부연을 붙이지 않는다.
   `푸시` 는 `git branch -r --contains <해시>` 출력이 있으면 체크한다.
3. 본문 `3. 결과` · `4. 개선점` · `5. 출처` · `6. 산출물` 을 `update_content` 로 채운다 — 본문 전체를 다시 쓰지 않는다.
   `3. 결과` 의 항목(`## 검증 방법과 결과`, `## 남은 일 / 후속 조치`)은 제목2로 두고 내용은 다음 줄에 쓴다.
   앵커를 잡을 때 섹션은 `#`, 항목은 `##` 이므로 `#` 개수를 틀리지 말 것.
4. `상태=검증` 으로 옮긴다. **`완료` 로는 올리지 않는다** (사람 확인 후).
5. 카드 URL과 채운 내용을 요약해 알린다.
