Notion 작업 카드에 기록된 세션으로 되돌아가기 위한 명령을 만든다.

대상: $ARGUMENTS

## 절차

1. **대상 특정**
   - 인자가 UUID 형태면 그대로 세션ID로 쓴다.
   - `AGT-` 로 시작하면 `ID` 속성으로 카드를 찾는다.
   - 그 외 문자열이면 `작업명` 에서 검색한다.
   - 인자가 비었으면 `세션ID` 가 채워진 카드를 `수정일시` 내림차순으로 최대 10건 조회해
     `ID · 작업명 · 에이전트 · 상태 · 수정일시` 를 표로 보여주고 사용자에게 고르게 한다.

2. **세션ID 확인** — 카드의 `세션ID` 가 비어 있으면 거기서 멈춘다.
   그 세션은 되살릴 수 없다고 알리고, 카드 링크만 준다. 추측한 ID로 시도하지 않는다.

3. **명령 생성** — `skills/notion-worklog-skill/scripts/resume.sh <세션ID>` 를 실행한다.
   스크립트가 클라이언트(Claude Code / Codex)와 실제 작업 디렉토리를 트랜스크립트에서 찾아
   `cd <경로> && <resume 명령>` 형태로 만들어 준다.
   종료코드가 1이면 로컬에 세션 로그가 없는 것이다 — 다른 머신에서 만든 세션일 수 있다고 알린다.

4. **출력** — 생성된 명령을 코드블록으로 보여주고, 사용자가 `!` 를 붙여 바로 실행할 수 있게 안내한다.
   대상 카드 링크도 한 줄로 같이 준다.

## 실행하지 말 것

이 명령은 **명령 문자열을 만들어 주기만 한다.** 에이전트가 직접 `claude --resume` 이나
`codex resume` 를 실행하면 현재 세션 안에서 중첩 대화형 세션이 뜨고 그대로 멈춘다.
반드시 사용자가 직접 실행하게 한다.
